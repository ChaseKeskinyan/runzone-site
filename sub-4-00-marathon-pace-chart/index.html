How to train for a sub-4:00 marathon

  • Easy pace: about 10:09–11:09 per mile, or in Zone 2. Most of your miles should be here.
  • Weekly volume: many runners aiming for this goal run around 35–55 miles a week.
  • Long run: build to 16–20 miles.
  • One quality session a week: intervals or a tempo run near goal pace.
  • Pacing on race day: start slightly slower than 9:09/mile and speed up in the second half.

FAQ

What pace do I need for a sub-4:00 marathon?

About 9:09 per mile (5:41 per km), held for the full marathon.

How fast should my easy runs be for a sub-4:00 marathon?

Roughly 10:09–11:09 per mile, or whatever keeps you in Zone 2. Easy runs should feel conversational.

How much should I run per week for a sub-4:00 marathon?

Many runners aiming for this goal run around 35–55 miles a week, with a long run of 16–20 miles. Build up gradually, about 10% a week at most.
