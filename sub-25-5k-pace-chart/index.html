How to train for a sub-25 minutes 5K

  • Easy pace: about 9:03–10:03 per mile, or in Zone 2. Most of your miles should be here.
  • Weekly volume: many runners aiming for this goal run around 15–25 miles a week.
  • Long run: build to 5–7 miles.
  • One quality session a week: intervals or a tempo run near goal pace.
  • Pacing on race day: start slightly slower than 8:03/mile and speed up in the second half.

FAQ

What pace do I need for a sub-25 minutes 5K?

About 8:03 per mile (5:00 per km), held for the full 5K.

How fast should my easy runs be for a sub-25 minutes 5K?

Roughly 9:03–10:03 per mile, or whatever keeps you in Zone 2. Easy runs should feel conversational.

How much should I run per week for a sub-25 minutes 5K?

Many runners aiming for this goal run around 15–25 miles a week, with a long run of 5–7 miles. Build up gradually, about 10% a week at most.
